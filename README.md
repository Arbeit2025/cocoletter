# Coco’s Letter

Cocoletter は、Flask と SQLite で作られたシンプルなメモアプリです。
  
ブラウザから短い文章を保存し、一覧表示し、不要になったら削除できます。

小さくてシンプルな「自分用メモ置き場」を目的としています。


Single-file Flask + SQLite memo app.

## Features
- メモの保存
- メモ一覧表示
- メモ削除

## Run (local)
pip install -r requirements.txt
python app.py
